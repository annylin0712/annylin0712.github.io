# Personal Writing Website

A clean, responsive two-column writing portfolio. The left side has an introduction; the right side lists writing. Clicking an article opens its full text.

## Customize
1. In `index.html`, replace “Your Name” and edit the introductory paragraph.
2. Add articles to the `articles` array at the bottom of `index.html`. Each needs `slug`, `title`, `date`, `category`, `summary`, and HTML `body`.
3. Add public contact and CV links only when ready.
4. Test the page before sharing it on your résumé.

## GitHub Pages
This repository is `annylin0712/jiaqilin0712.github.io`. It is a **project site**, not the account's root user site, because the owner's login is `annylin0712`.

The expected project URL is `https://annylin0712.github.io/jiaqilin0712.github.io/`.

If you want the shorter `https://annylin0712.github.io/` URL, rename the repository to `annylin0712.github.io` and set up Pages there.
